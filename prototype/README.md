# Прочность печати — расчёт FDM-деталей по G-code

Программа берёт G-code из слайсера (OrcaSlicer, Bambu Studio, PrusaSlicer, SuperSlicer, Cura, Simplify3D), восстанавливает по траекториям сопла, как именно напечатана деталь, и методом конечных элементов считает перемещения, напряжения и запас прочности. Учитывается главное отличие печатных деталей от литых: пластик вдоль нити прочнее, чем поперёк, а слабее всего — сцепление между слоями.

Это прототип: считает быстро и наглядно, точность на тестовых задачах — несколько процентов (см. «Проверка точности»), но свойства пластика в базе типовые. Для ответственных деталей впишите свои значения (раздел «Свои материалы»).

## Быстрый старт

Нужен Python 3.10 или новее (подходят и самые свежие версии). Из библиотек — только numpy и scipy, для них есть готовые сборки под все системы, компилятор не нужен.

**Windows.** Установите Python с [python.org](https://www.python.org/downloads/) — при установке поставьте галочку «Add python.exe to PATH». Затем дважды щёлкните `start_windows.bat`. Первый запуск ставит библиотеки (1–3 минуты, нужен интернет), дальше программа открывается сразу. В браузере откроется приложение.

**macOS / Linux.** В терминале в папке программы:

```
./start_mac_linux.sh
```

**Вручную:**

```
python -m pip install -r requirements.txt
python -m fdmfea gui
```

Приложение работает только на вашем компьютере (адрес `http://127.0.0.1:8765`), интернет ему не нужен. Закрыть — окно консоли, Ctrl+C.

## Как пользоваться

1. **Деталь.** Нарежьте модель в слайсере с теми настройками, с которыми будете печатать, сохраните `.gcode` и перетащите его в окно (или «Открыть G-code»). Ориентация на столе, число стенок, процент и рисунок заполнения — всё берётся из файла. Кнопка «Пример» открывает готовый кронштейн с заданными нагрузками.
2. **Материал.** Пластик определяется из G-code автоматически. Поле «Нужный запас» — сколько запаса вы хотите (2 для обычных деталей, 3 для ответственных).
3. **Закрепления.** Щёлкните по поверхности на модели и нажмите «Закрепить выбранное». Инструменты выбора:
   - **Грань** — плоская грань целиком;
   - **Отверстие** — стенка отверстия или цилиндра (щёлкните внутри отверстия);
   - **Кисть** — всё в заданном радиусе от точки.
   Shift+щелчок добавляет к выбору, Alt+щелчок убирает, Esc снимает выбор. У закрепления можно оставить только нужные оси: например, «упор в стену» держит только по одной оси.
4. **Нагрузки.** Выберите поверхность, тип нагрузки и нажмите «+ Нагрузка». Каждый расчётный случай считается отдельно — например, «вес лампы, длительно» и «рывок рукой».
5. **Рассчитать.** Справа — карта запаса прочности, черно-белая метка показывает слабое место. Кнопка «Слабое место» делает разрез по слою через него. «Отчёт» сохраняет самостоятельный HTML-файл с 3D-моделью — его можно отправить кому угодно.

Задание (закрепления, нагрузки, материал) сохраняется кнопкой «Сохранить задание» и загружается обратно. При смене детальности сетки выбранные поверхности переносятся автоматически.

### Оси и координаты

Все направления — в осях принтера: **X, Y** — по столу, **Z** — вверх по слоям. Если деталь в работе стоит иначе, чем печаталась, направление силы задаётся в осях печати: например, кронштейн, напечатанный на боку, нагружается весом лампы вдоль −Y, а не −Z. Координаты в подсказках и в файле задания — в миллиметрах от минимального угла габарита детали.

## Виды нагрузок

| Нагрузка | Что задаётся | Пример |
|---|---|---|
| Сила | Н, направление | рука давит на ручку |
| Подвешенный груз | кг, направление | лампа на крючке |
| Нагрузка на отверстие | Н, направление; распределяется по косинусу на ту сторону отверстия, куда давит винт или ось | болтовое соединение, ось шарнира |
| Давление | МПа, по нормали к поверхности | давление жидкости, прижим |
| Крутящий момент | Н·мм, ось | ручка крана, вал |
| Удар падающим грузом | кг и высота падения, мм | упавший предмет; энергетический метод, оценка с запасом |
| Заданное перемещение | мм по осям | защёлка, натяг; заодно считается усилие |
| Собственный вес / перегрузка | в g | тряска, перевозка |

**Характер нагрузки** меняет допустимое напряжение:

- *кратковременная* — как в испытании на растяжение;
- *длительная* — учитывает ползучесть: прочность снижается до 40–50% от кратковременной, прогиб растёт;
- *циклическая* — усталость по числу циклов (кривая S–N: при 10⁶ циклов около 25% от статической прочности).

**Температура** снижает модуль и прочность по мере приближения к теплостойкости пластика (HDT) и предупреждает, если она превышена. Галочка «тепловое расширение» добавляет напряжения от нагрева зажатой детали.

## Как читать результат

- **Запас прочности** — во сколько раз можно увеличить нагрузку до разрушения. Меньше 1 — сломается.
- **Выдержит до** — та же информация в единицах нагрузки: «≈ 54 Н», «≈ 5,4 кг», «падение с ≈ 116 мм».
- **Что разрушится первым** — вид разрушения в слабом месте:
  - *вдоль нити* — разрыв или смятие самого пластика, лучший случай;
  - *между нитями в слое* — отрыв соседних валиков;
  - *между слоями* — расслоение по Z, типичная слабость печати. Если видите его, попробуйте повернуть деталь на столе.
- **Структура печати** показывает, где стенки, где сплошное и где разреженное заполнение — так видно, что программа поняла из G-code.

Острые внутренние углы на расчётной сетке (она состоит из кубиков) дают завышенный пик напряжений. Если слабое место в таком углу, лучшее решение и для расчёта, и для реальной детали — скругление.

## Проверка точности

Тесты в папке `tests` (запуск: `python tests/test_cantilever.py` и др.):

| Задача | Расчёт | Аналитика | Расхождение |
|---|---|---|---|
| Консоль 100×10×10 мм, PLA, печать плашмя: прогиб | 6,66 мм | 6,52 мм | +2% |
| то же: запас посередине пролёта | 3,71–3,77 | 3,73 | ±1% |
| Консоль, печать стоя (изгиб поперёк слоёв): прогиб | 9,42 мм | 9,16 мм | +3% |
| то же: запас посередине, вид разрушения | 2,00–2,01, расслоение | 2,00 | <1% |

Материалы в базе сверены с паспортами производителей: расчётный образец с укладкой ±45° даёт прочность X-Y, а образец поперёк слоёв — прочность Z из паспортов Bambu Lab и Polymaker.

## Как это устроено

1. **Разбор G-code** (`gcode.py`): движения с экструзией превращаются в отрезки с объёмом пластика, толщиной слоя и типом линии (стенка, сплошное, разреженное заполнение). Поддержки, юбка, кайма, черновая башня, стартовый и финальный код отбрасываются. Поддерживаются дуги G2/G3, абсолютная и относительная экструзия.
2. **Вокселизация** (`voxelize.py`): деталь разбивается на кубики, сетка выравнивается по краям детали и по границам слоёв. Для каждого кубика считаются доля пластика и распределение направлений нитей. Разреженное заполнение усредняется по ячейке рисунка.
3. **Материал** (`materials.py`): в каждом кубике — своя анизотропная жёсткость, сложенная из нитей разных направлений; для разреженного заполнения — своя модель по рисунку (сетка, гироид и т.д.).
4. **МКЭ** (`fem.py`): шестигранные элементы с несовместными модами — правильно передают изгиб даже при двух элементах по толщине. Решатель — собственный алгебраический многосеточный (сглаженная агрегация по блокам вокселей) с сопряжёнными градиентами; нужны только numpy и scipy.
5. **Разрушение** (`analysis.py`): напряжения пересчитываются в оси каждой нити, запас считается по критерию Хоффмана (разные прочности на растяжение и сжатие по трём направлениям). Длительность, циклы и температура меняют допускаемые напряжения.

## Свои материалы

Свойства лежат в `fdmfea/materials.json`; в приложении их можно поправить в разделе «Свойства материала». Значения задаются в осях валика: **1** — вдоль нити, **2** — поперёк нити в слое, **3** — по Z (между слоями). Достаточно знать четыре числа: модуль упругости и прочность на растяжение вдоль нити (`E1`, `Xt`) и поперёк слоёв (`E3`, `Zt`). Остальные можно оставить типовыми.

Простой способ подогнать числа под свой принтер — испытать два бруска и посчитать их в этой же программе:

1. Нарежьте и напечатайте брусок 100×10×4 мм дважды: плашмя (заполнение 100%) и стоя.
2. Положите брусок на две опоры с пролётом 80 мм и подвешивайте посередине груз, пока не сломается. Запишите массу груза.
3. Откройте G-code бруска в программе, закрепите опоры (кисть по нижней грани у концов, ось Z), задайте этот груз посередине и посчитайте.
4. Если программа показывает запас, например, 0,8, значит реальный пластик в 1/0,8 = 1,25 раза прочнее, чем в базе: умножьте на 1,25 прочность того направления, которое указано в «Что разрушится» (`Xt` для бруска плашмя, `Zt` для бруска стоя).

Так вы учтёте сразу всё: пластик, температуру, обдув и скорость печати вашего принтера.

## Командная строка и файл задания

```
python -m fdmfea run деталь.gcode задание.json -o отчёт.html
python -m fdmfea info деталь.gcode        # что извлечено из G-code, габарит
python -m fdmfea materials                 # список материалов
```

Файл задания — JSON (или YAML, если установлен пакет `pyyaml`). Области в нём можно задавать геометрически, в мм от угла детали:

```json
{
  "title": "Кронштейн",
  "material": "PETG",
  "target_sf": 2,
  "fixtures": [
    {"name": "винты", "where": {"hole": {"axis": "x", "center": [12, 15], "radius": 2.5}}},
    {"name": "стена", "where": {"side": "xmin"}, "components": "x"}
  ],
  "cases": [
    {"name": "лампа 2 кг", "duration": "long", "temperature": 30,
     "loads": [{"type": "mass", "where": {"hole": {"axis": "y", "center": [62, 15], "radius": 4}}, "kg": 2, "direction": "-y"}]},
    {"name": "удар", "loads": [{"type": "impact", "where": {"side": "xmax"}, "kg": 0.3, "height": 100, "direction": "-y"}]}
  ]
}
```

Способы задать область: `{"side": "xmin|xmax|ymin|ymax|zmin|zmax"}`, `{"box": {"min": [x,y,z], "max": [x,y,z]}, "normal": "+y"}`, `{"hole": {"axis": "z", "center": [x, y], "radius": r}}`, `{"sphere": {"center": [x,y,z], "radius": r}}`, `{"faces": [...]}` (номера граней, так сохраняет приложение). Типы нагрузок: `force`, `mass`, `bearing`, `pressure`, `moment`, `impact`, `displacement`, `gravity`. Направление — `"-z"`, `"+x"`, `"normal_in"`, `"normal_out"` или вектор `[x, y, z]`. Готовые задания — в папке `examples`.

## Ограничения

- Линейная упругость и малые перемещения: большие прогибы, контакт и трение не считаются. Для TPU результат верен только при малых деформациях.
- Потеря устойчивости (выпучивание тонких стенок при сжатии) пока не считается.
- Поры, недоэкструзия, плохое сцепление слоёв из-за обдува или сквозняка в расчёт не входят — это закладывается в запас прочности или в собственные значения материала.
- Разрешение сетки ограничено числом элементов. Тонкостенные детали (абажуры, вазы) считайте с детальностью «точная» и выше.

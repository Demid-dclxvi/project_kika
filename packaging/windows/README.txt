Kika — расчёт прочности деталей для FDM-печати
==============================================

kika-gui.exe — окно: открыть G-code или модель (STL, 3MF, STEP), выбрать на детали закрепления
и места нагрузок, посчитать и посмотреть результат в 3D. Модель режет свой слайсер: слой,
стенки, заполнение (сетка, гироид, кубы, соты, 3D-соты…), поддержки (обычные, древовидные) и
поворот детали на столе задаются в окне, G-code этой нарезки можно сохранить и напечатать.
«Подобрать» предлагает положение детали и настройки печати под две цели из трёх: быстро,
экономно, прочно. Кнопка «Пример» открывает кронштейн из папки examples; там же
bracket_L.job.json — пример задания по модели 3MF, bracket_L.step — та же деталь в STEP.

kika.exe — то же из командной строки: kika деталь.gcode — сведения о печати,
kika run задание.json — расчёт и отчёт, kika slice модель.stl — G-code своей нарезки,
kika advise задание.json --goals economy,strength — подбор положения и настроек печати.
Задание, сохранённое в окне, kika run понимает.

Установка не нужна: распакуйте архив целиком в любую папку и запустите kika-gui.exe.
Все файлы рядом с программой нужны ей для работы:
  Qt6*.dll и папки platforms, styles, imageformats, translations — библиотеки окна (Qt);
  msvcp140*.dll, vcruntime140*.dll — среда выполнения Visual C++;
  TK*.dll — OpenCascade для чтения STEP (LGPL-2.1, можно заменить своей сборкой 8.0.1);
  opengl32sw.dll — программный OpenGL для компьютеров без драйвера видеокарты.

Если окно не открывается или 3D-вид пустой (старый драйвер, удалённый рабочий стол,
виртуальная машина) — запустите kika-gui-software.cmd: он включает программный OpenGL.

Если Windows покажет «Система Windows защитила ваш компьютер» — программа пока без цифровой
подписи: «Подробнее» → «Выполнить в любом случае».

Сторонние компоненты и лицензии — в папке licenses (THIRD_PARTY.md). Окно построено на Qt 6
(LGPL-3.0): библиотеки Qt лежат отдельными файлами Qt6*.dll, их можно заменить своей сборкой
Qt той же версии. Исходники Qt: https://download.qt.io/official_releases/qt/
Исходники Kika: https://github.com/Demid-dclxvi/project_kika
